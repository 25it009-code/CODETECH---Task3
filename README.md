# Interactive Quiz Application – Project Overview

## Introduction

The **Interactive Quiz Application** is a web-based project used to conduct quizzes in an interactive and user-friendly manner.
It allows users to answer multiple-choice questions and instantly view their scores.

This project is developed using:

* HTML
* CSS
* JavaScript

The application helps improve learning and programming skills through interactive question-and-answer sessions.

---

# Objectives

* To create an interactive quiz system
* To evaluate user knowledge
* To calculate scores automatically
* To improve JavaScript programming skills
* To provide an engaging learning experience

---

# Features

## 1. Multiple Choice Questions

Users can answer questions by selecting one option from multiple choices.

---

## 2. Score Calculation

The application automatically:

* Checks answers
* Calculates score
* Displays final result

---

## 3. Interactive User Interface

The project provides:

* Attractive design
* Easy navigation
* Responsive layout

---

## 4. Next Question Functionality

Users can move to the next question using the “Next Question” button.

---

## 5. Result Display

At the end of the quiz, the application shows:

* Total score
* Correct answers count

---

# Technologies Used

| Technology | Purpose                           |
| ---------- | --------------------------------- |
| HTML       | Structure of the quiz application |
| CSS        | Styling and layout design         |
| JavaScript | Quiz logic and score calculation  |

---

# Working Process

1. Quiz questions are stored in JavaScript objects
2. Questions are displayed one by one
3. User selects an answer
4. Application checks whether the answer is correct
5. Score is updated automatically
6. Final result is displayed after completing all questions
